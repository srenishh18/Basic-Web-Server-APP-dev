Request Flow & Working Process

Fig. 4.7 illustrates the internal life cycle of an incoming HTTP request through the Node.js event loop, Express middleware pipeline, route resolution, and HTTP response delivery.

Fig. 4.7

Request Flow Diagram & Server Process

Click "Run Request Flow Simulation" to visualize how an HTTP packet travels step-by-step through each layer of the Node.js server stack.

1
1. HTTP Client Request
Client browser issues an HTTP Request (e.g. GET /request-flow) over TCP/IP socket targeting port 3000.
↓
2
2. Node.js Event Loop Ingestion
Node.js HTTP server receives the socket connection and delegates the request object (req) and response object (res) to Express.
↓
3
3. Express Middleware Pipeline
Request flows sequentially through global middleware: express.json(), body parser, request logger, and express.static().
↓
4
4. Route Match & Controller Execution
Express evaluates route table. If match is found (e.g., app.get('/request-flow')), controller handler executes business logic.
↓
5
5. HTTP Response Stream & Final 200 OK
Server transmits HTTP headers (Status 200, Content-Type: text/html) and body back to browser, closing socket stream.
